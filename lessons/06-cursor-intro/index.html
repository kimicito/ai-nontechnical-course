6.1 Cursor vs чат с ИИ: теория и установка

⏱ 15 минут • 📋 Теория + практика

🎯 В чём суть

Вы уже умеете разговаривать с ИИ в чате. Cursor — это следующий уровень: ИИ не просто советует, а сам пишет программы, создаёт файлы и собирает готовые сайты и базы данных. Без единой строки кода, написанной вручную.

Чем это отличается от чата:
  • В чате ИИ присылает код текстом — вы копируете вручную
  • В Cursor ИИ сам создаёт и сохраняет файлы в вашей папке
  • Cursor видит весь проект целиком и помнит, что делал раньше
  • Cursor сам находит и исправляет ошибки

⚔️ Чат с ИИ vs Cursor

Что делаем Обычный чат Cursor
Создать файл ИИ даёт код → вы копируете → создаёте файл → вставляете → сохраняете Нажали Enter — файл уже создан и сохранён
Исправить ошибку Вы пересказываете ошибку текстом Cursor видит код и сообщение об ошибке — чинит сам
Помнит контекст Каждый раз объясняете заново Видит все файлы проекта и историю изменений
Скорость Минуты на копирование и вставку Секунды — нажали и готово
Аналогия для запоминания:
Чат с ИИ — это советчик по телефону: подскажет, а руками работаете вы.
Cursor — это мастер в вашей мастерской: у него есть инструменты и материалы, он делает работу сам, а вы принимаете результат.

📈 Как было → Как стало

Раньше

Идея → заявка в ИТ → очередь → техзадание → разработчик → недели или месяцы → правки → ещё недели.

Маленькие задачи («нам бы табличку поставщиков с поиском») до разработчика просто не доходили.

Сейчас с Cursor

Вы описываете задачу обычными словами → ИИ пишет код → вы смотрите результат → просите поправить → готово за вечер.

Типичный маленький проект: от получаса до одного вечера.

🛠️ Что такое Cursor простыми словами

Cursor — это редактор для работы с файлами программ, внутри которого живёт ИИ-ассистент. Как Word, только вместо документов — файлы сайта или базы данных.

✅ Что Cursor умеет

  • Написать программу с нуля по описанию на русском языке
  • Дорабатывать по просьбам: «сделай кнопку заметнее», «добавь столбец ИНН»
  • Находить и исправлять ошибки
  • Объяснять простыми словами, что он сделал

⚠️ Чего Cursor НЕ умеет

  • Читать мысли: всё, что вы не написали, он додумает сам — и может додумать не так
  • Гарантировать правильность: проверять глазами придётся вам
  • Отвечать за сохранность данных: копии делаете вы

Cursor работает на Windows, macOS и Linux. Есть бесплатный тариф с ограничениями — для первых проектов его хватает.

📥 Установка и первый запуск

1. Скачайте программу
Зайдите на cursor.com и нажмите Download. Сайт сам предложит версию под вашу систему.
2. Установите как обычно
Запустите скачанный файл и нажимайте «Далее». Никаких специальных настроек не нужно.
3. Зарегистрируйтесь
При первом запуске Cursor попросит войти в аккаунт. Подойдёт рабочая почта или Google-аккаунт.
4. Создайте папку проекта
Создайте на компьютере пустую папку, например «Мой сайт», и откройте её в Cursor: File → Open Folder.
Как понять, что всё готово:
Cursor открыт, слева видна пустая панель с названием вашей папки. Всё — можно начинать разговор с ИИ.

🖥️ Интерфейс: три зоны

🗂️ Зона 1 — Файлы проекта

Слева. Здесь Cursor показывает все файлы, которые он создал: index.html, style.css, script.js и другие.

💻 Зона 2 — Код

В центре. Его пишет ИИ, вы можете сюда вообще не заглядывать. Но если интересно — можете посмотреть, что получилось.

💬 Зона 3 — Чат с ИИ (главная)

Справа. Сюда вы пишете запросы. Рабочий приём: держите чат открытым всегда — 90% работы происходит именно там.

🔑 Горячие клавиши

Ctrl + L — открыть чат с ИИ

Ctrl + I — режим «агент»: ИИ сам создаёт и правит файлы

Ctrl + ` — панель снизу: видно ошибки

На Mac вместо Ctrl — Cmd

💡 Совет: Ничего не бойтесь сломать. Худшее, что случится — ИИ напишет не то. Тогда просто пишете в чат: «Отмени, верни как было».

✅ Итог урока

  • Cursor — это редактор с встроенным ИИ, который сам пишет код по вашим словам
  • Отличается от чата тем, что сам создаёт файлы, видит проект целиком и чинит ошибки
  • Установка простая: скачал, установил, зарегистрировался, открыл папку
  • Главные клавиши: Ctrl+I для агента, Ctrl+L для чата
