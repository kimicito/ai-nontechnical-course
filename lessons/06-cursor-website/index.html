6.3 Проект: сайт отдела закупок

⏱ 20 минут • 🛠️ Практика

🎯 Цель проекта

Создать одностраничный сайт отдела закупок: с контактами, регламентами и формой заявки. Без единой строки кода, написанной вручную.

Что получится: страница в браузере с разделами, таблицей контактов и формой. Можно показать коллегам на встрече.

🚀 Шаг 1. Один запрос — и сайт уже существует

Что делаете

  1. Создайте папку на компьютере, например «Сайт закупок»
  2. Откройте её в Cursor: File → Open Folder
  3. Нажмите Ctrl+I (режим агента)
  4. Вставьте готовый запрос ниже
  5. Нажмите Enter
📋 ГОТОВЫЙ ЗАПРОС — СКОПИРУЙТЕ И ПОДСТАВЬТЕ СВОЁ
«Создай в этой папке одностраничный сайт отдела закупок компании [название].

Для кого: для сотрудников склада и поставщиков.

Разделы:
1) чем занимается отдел,
2) регламенты и формы заявок (списком),
3) контакты сотрудников (таблица: имя, роль, почта, телефон),
4) частые вопросы.

Стиль: строгий, белый фон, тёмно-серый текст, акцент — [фирменный цвет]. Без лишних эффектов. Тексты напиши сам на русском».

Что происходит дальше

ИИ в режиме агента сам создаёт файлы: index.html, style.css и другие. Вы видите в чате, что он делает.

Ваша роль на этом шаге: только наблюдать. Когда ИИ закончит, он напишет, что сделал.

⚠️ Если ИИ спрашивает разрешения выполнить команду — смело нажимайте «Run» / «Выполнить».

🔧 Шаг 2. Доработка: с первого раза идеально не бывает

Рабочий цикл — повторяете 5–10 раз

  1. Смотрите сайт в браузере (двойной клик по index.html)
  2. Замечаете, что не так
  3. Пишете одну правку в чат
  4. Обновляете страницу (F5)
📝 Примеры хороших правок
  • «Сделай шапку тёмно-синей, а текст в ней белым»
  • «В таблице контактов добавь столбец «рабочие часы»»
  • «Замени придуманные тексты в разделе «О нас» на этот текст: …»
  • «Кнопку «Отправить заявку» сделай крупнее и оранжевой»
  • «Убери раздел «Новости» совсем»
✅ Критерий завершения шага: в папке появились файлы, и при открытии index.html в браузере вы видите страницу с разделами из вашего запроса.

🌐 Шаг 3. Как показать сайт коллегам

🏠 Уровень 1. Показать со своего компьютера

Просто открываете index.html и показываете на встрече. Подходит для демонстрации идеи руководителю.

Ничего настраивать не нужно.

📁 Уровень 2. Раздать коллегам по офису

Скопируйте всю папку проекта на общий сетевой диск или отправьте архивом. Коллега открывает index.html у себя — сайт работает.

Важно: отправлять нужно всю папку целиком, не один файл.

🌍 Уровень 3. Адрес в интернете

Бесплатные сервисы вроде Netlify Drop: перетаскиваете папку мышкой на страницу — получаете ссылку, которая открывается отовсюду.

Можно попросить ИИ: «Объясни по шагам, как выложить мой сайт на Netlify».

⚠️ Честная граница

Такой сайт — отличный инструмент для внутренних задач и для проверки идей.

Но если это будущий официальный сайт компании с приёмом заявок от клиентов, защитой данных и юридическими требованиями — это уже задача для ИТ-отдела или подрядчика. Ваша самоделка станет для них отличным наглядным техзаданием.

✅ Итог урока

  • Создали сайт за один запрос в режиме агента (Ctrl+I)
  • Доработали внешний вид через 5–10 итераций правок
  • Узнали три способа показать результат коллегам
  • Поняли границу: внутренний инструмент vs официальный сайт
