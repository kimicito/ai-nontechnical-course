Уровень 12 — Дирекция по качеству

12.1 Внутренние задачи Качества

⏱ 20 мин · для инженеров по качеству и аудиторов СМК
Закрытый контур (on-prem)
Все задачи этого урока работают с реальными данными производства, рекламациями, внутренними несоответствиями, финансовыми показателями. Используйте внутреннюю модель или локальный LLM.

Почему on-prem критичен для качества

Дирекция по качеству оперирует чувствительными данными: рекламации клиентов, внутренние несоответствия, финансовые потери от брака, технологические параметры. Передача такой информации во внешние сервисы создаёт риски утечки коммерческой тайны.

Когда on-prem обязателен:
  • Root-cause анализ реальных несоответствий (5 Why, Ishikawa)
  • 8D-отчёты по рекламациям клиентов
  • Аудит СМК с реальными данными процессов
  • Разработка и пересмотр технических условий (ТУ)
  • Анализ Cost of Quality (COPQ) с реальными цифрами
  • R&D: анализ патентов конкурентов с привязкой к продукту
  • Обработка претензий клиентов с финансовыми требованиями
  • Внутренние корректирующие действия (КД) и предупреждающие действия (ПД)
  • Статистический анализ процессов (SPC) с реальными данными
  • Оценка рисков поставщиков по качеству

1. Root-cause анализ несоответствий (5 Why + Ishikawa)

Анализ причин несоответствия с использованием классических методов — структурированный текстовый вывод.

Пример промпта (on-prem)
Проведи root-cause анализ несоответствия:

Событие: [УКАЖИТЕ ПРОДУКТ], партия [УКАЖИТЕ НОМЕР], дата [УКАЖИТЕ ДАТУ]
Несоответствие: [УКАЖИТЕ ПАРАМЕТР] вышел за пределы ТУ ([УКАЖИТЕ ФАКТ] vs допустимое [УКАЖИТЕ НОРМУ])

Метод 1 — 5 Why:
Почему произошло несоответствие? → [ответ]
Почему [ответ]? → [ответ]
... (5 уровней)

Метод 2 — Диаграмма Ishikawa:
Категории: Люди, Метод, Материал, Машина, Среда, Измерения
Для каждой: потенциальные факторы

Вывод: корневая причина (1–2), рекомендации по КД и ПД.

Результат: структурированный анализ, экономит 2–3 часа.

2. Подготовка 8D-отчёта

8D (Eight Disciplines) — стандартный отчёт для рекламаций. LLM помогает структурировать и заполнить.

Пример промпта
Подготовь 8D-отчёт по рекламации клиента:

D0: Симптом — [УКАЖИТЕ ПРОБЛЕМУ]
D1: Команда — [УКАЖИТЕ СОСТАВ]
D2: Описание проблемы — [УКАЖИТЕ ДЕТАЛИ]
D3: Временные меры — [УКАЖИТЕ ДЕЙСТВИЯ]
D4: Root-cause — [результат анализа]
D5: Корректирующие действия (КД) — [меры]
D6: Проверка эффективности КД — [критерии]
D7: Предупреждающие действия (ПД) — [меры]
D8: Поздравление команды — [закрытие]

Сформулируй текст для каждого раздела в корпоративном стиле.

Результат: готовый 8D-отчёт, экономит 3–4 часа.

3. Аудит СМК: подготовка и анализ

Подготовка чек-листов, анализ несоответствий, формирование заключений.

Пример промпта
Подготовь план внутреннего аудита СМК ISO 9001:

Область: [УКАЖИТЕ ПРОЦЕСС / ОТДЕЛ]
Период: [УКАЖИТЕ ДАТЫ]

Требования:
1. Чек-лист по ISO 9001:2015 (разделы 4–10)
2. Вопросы с привязкой к документам компании
3. Проверка выполнения КД и ПД предыдущего аудита
4. Анализ KPI процесса

Формат: таблица (№, требование, вопрос, документ, результат, несоответствие).

Результат: готовый план аудита, экономит 2 часа.

4. Разработка и пересмотр технических условий (ТУ)

Генерация текста ТУ на основе требований заказчика и внутренних стандартов.

Пример промпта
Подготовь проект ТУ на [УКАЖИТЕ ПРОДУКТ]:

Исходные данные:
- Назначение: [УКАЖИТЕ]
- Технические параметры: [УКАЖИТЕ]
- Требования заказчика: [УКАЖИТЕ]
- Ссылочные стандарты: [УКАЖИТЕ ГОСТ/ISO]

Структура:
1. Область применения
2. Технические требования
3. Методы контроля
4. Правила приёмки
5. Маркировка, упаковка, транспортирование
6. Гарантии изготовителя

Требования: юридически корректный текст, ссылки на действующие стандарты.

Результат: готовый проект ТУ, экономит 4–5 часов.

5. Cost of Quality (COPQ) — анализ затрат на качество

Классификация затрат, расчёт индексов, рекомендации по снижению.

Пример промпта
Проанализируй Cost of Quality за [УКАЖИТЕ ПЕРИОД]:

Данные:
- Затраты на профилактику: [УКАЖИТЕ СУММУ] (обучение, аудиты, планирование)
- Затраты на оценку: [УКАЖИТЕ СУММУ] (инспекции, тестирование, сертификация)
- Внутренние потери: [УКАЖИТЕ СУММУ] (брак, переделка, простои)
- Внешние потери: [УКАЖИТЕ СУММУ] (рекламации, возвраты, штрафы)

Сделай:
1. Распределение по категориям (%)
2. Тренд vs прошлый период
3. Сравнение с отраслевыми бенчмарками (если известны)
4. Рекомендации: где сократить потери, где увеличить профилактику
5. ROI на вложения в качество

Результат: аналитический отчёт для руководства, экономит 3–4 часа.

6. R&D: анализ патентной ситуации

Поиск аналогов, оценка свободы действия (freedom to operate), анализ конкурентов.

Пример промпта
Проанализируй патентную ситуацию для [УКАЖИТЕ ТЕХНОЛОГИЮ / ПРОДУКТ]:

Исходные данные (внутренние):
- Наша технология: [УКАЖИТЕ]
- Страны интереса: [УКАЖИТЕ]
- Конкуренты: [УКАЖИТЕ]

Задачи:
1. Патентный ландшафт: кто и что патентовал в этой области
2. Оценка freedom to operate (FTO) для нашей технологии
3. Белые пятна (white space) — где можно патентовать
4. Риски нарушения патентов конкурентов
5. Рекомендации по патентной стратегии

Важно: патентные данные — публичны, но анализ с привязкой к нашей технологии — внутренний.

Результат: стратегический анализ, экономит 5–6 часов патентного поверенного.

Проверка знаний

Вопрос 1: Почему root-cause анализ — on-prem?

Потому что содержит реальные данные производственных несоответствий
Потому что методология 5 Why — коммерческая тайна
Только если анализ включает финансовые потери

Вопрос 2: Можно ли в облаке разработать ТУ?

Да, ТУ — это публичный документ
Нет, ТУ содержит спецификации продукта — on-prem
Только общую структуру, без конкретных параметров

Вопрос 3: COPQ анализ — какой контур?

On-prem — содержит финансовые показатели и потери
Внешний ИИ — методология Cost of Quality общая
Гибрид — структура снаружи, цифры внутри
