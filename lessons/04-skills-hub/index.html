4.6 Skills: расширяем возможности агента

⏱ 10 мин · как находить и устанавливать готовые навыки
Что такое Skill?
Skill — это готовый модуль (инструкция + скрипты), который учит агента новому действию: проверять сайт, анализировать PDF, писать email, считать метрики. Вместо того чтобы объяснять агенту с нуля — просто устанавливаете skill и говорите «используй».

🗂️ Где искать skills

Основной каталог — ClawHub:

  • 90 000+ skills из 12 реестров
  • Фильтры по категориям: бизнес, разработка, креатив, исследования
  • Проверено сообществом — рейтинги и отзывы
  • Установка в одну команду
Примеры полезных skills:
  • 📊 financial-statement-analyzer — анализ отчётности
  • 🔍 seo-audit — проверка сайта на SEO
  • 📧 professional-email-composer — деловые письма
  • 📄 pdf — создание и редактирование PDF
  • 🌐 translation-craft — качественный перевод

⚡ Как установить skill

Способ 1: Через ClawHub (рекомендуется)

clawhub install <название-skill>

Пример:

clawhub install financial-statement-analyzer

Агент скачает skill, прочитает инструкцию и будет готов использовать.

Способ 2: Через Hermes Skills Hub

Каталог Hermes Agent Skills Hub — 90 000+ skills из разных источников:

npx skills add <автор>/<skill> -g

Например:

npx skills add bradautomates/claude-video -g

Способ 3: Вручную из GitHub

Если skill на GitHub — склонируйте репозиторий в папку skills/ вашего workspace:

cd ~/.openclaw/workspace/skills
git clone https://github.com/автор/skill-name.git

🛠️ Как использовать установленный skill

После установки просто скажите агенту:

«Проанализируй баланс компании за 2024 год используя financial-statement-analyzer»

Или:

«Проверь сайт logistoria.com на SEO-ошибки»

Агент сам прочитает SKILL.md, поймёт контракт и выполнит задачу.

🔐 Безопасность: проверяйте перед установкой

  • ✅ Читайте SKILL.md перед установкой — что делает skill
  • ✅ Проверяйте источник — доверенный автор или реестр
  • ✅ Смотрите, какие инструменты использует — только нужные
  • ❌ Не устанавливайте skills с подозрительных сайтов
  • ❌ Не давайте skills доступ к чувствительным данным без проверки

📋 Чеклист: первая установка

  1. Определите задачу (что хотите автоматизировать)
  2. Поищите skill на ClawHub
  3. Прочитайте описание и отзывы
  4. Установите: clawhub install <name>
  5. Протестируйте на безопасных данных
  6. Используйте в работе

🎯 Главное

Skills — это «приложения» для вашего AI-агента. Вместо того чтобы программировать с нуля — находите готовое, проверяйте и используйте. ClawHub и Hermes Hub — ваши магазины skills.
