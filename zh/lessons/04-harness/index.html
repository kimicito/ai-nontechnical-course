4.7 Harness：AI如何获得双手

⏱ 12 分钟 · 为什么提示词只占结果的5%
主要幻觉：写一个「聪明的提示词」，AI就会解决任务。

实际上，提示词只占结果的5%。另外95%是记忆、工具、循环和控制。这就是Harness。

🧑‍💼 失忆的实习生

想象一个才华横溢的实习生。他博览群书——读了半个互联网。但他有问题：

  • 失忆——不记得昨天的讨论。每次——从零开始。
  • 没有手——不能打开Excel、访问网站、发送邮件。
  • 自信地犯错——说得漂亮，但可能编造事实。
  • 一次性工作——给出答案就消失了。没有「尝试→失败→修正」。
问题：如果只给这个实习生一份好的简报（提示词），你会把多少实际任务交给他？

答案：几乎没有。他需要一个环境。这个环境就是Harness。

🔧 Harness的5个组成部分

1. 记忆和上下文 ——「实习生的秘书」

每次会议前必须有人准备文件夹：「这是合同、之前的通信、规章制度。」Harness从数千份文档中选择向模型展示什么。

例子：「更新我们的商业提案。」提示词不会决定——40份提案中的哪一份、它在哪里、哪个版本是最新的。周围的系统会决定。

2. 工具 ——「实习生的手」

模型只能生成文本。它不能：

  • 谷歌搜索汇率
  • 打开你的CRM
  • 在真正的Excel中计算
  • 发送邮件

Harness提供按钮：「搜索」「计算器」「读取文件」「发送邮件」。

区别：顾问说「你需要检查50份合同。」员工检查了并带来了一张表格。

3. 工作循环 ——「不是一个答案，而是一整天的工作」

复杂任务以循环方式解决：

思考 → 做一步 → 看结果 → 发现错误 → 修正 → 下一步…

一个提示词就像一次呼吸。你不能靠一次呼吸跑完马拉松。Harness将循环运行10、50、100次。

例子：「分析200条客户评论。」提示词——给出漂亮但虚构的总结。Harness智能体——分批阅读、计数、验证，并展示依据了哪些评论。

4. 质量控制 ——「签字的主管」

实习生 confidently 犯错。因此需要检查：与来源核对、在发给客户之前再看一遍。

提示词中的「请不要犯错」就像桌上的「别担心」贴纸。你需要的是机制，不是请求。

5. 边界和安全 ——「访问权限和规章制度」

你不会在第一天给实习生保险箱的钥匙。Harness定义：可以读取哪些文件、在哪里写入、多少次尝试、何时询问人类。

没有边界，智能体可能：删除错误的文件、无限循环、把邮件发给错误的人。

👁️ 你看到的 vs 实际发生的

你看到的实际发生的
「我写了一个聪明的提示词」系统从你的文件和历史中收集了上下文
「AI搜索了互联网」Harness调用了搜索工具并将结果输入模型
「AI自己修正了错误」Harness运行了循环：尝试 → 错误 → 重试
「AI在20分钟内完成了报告」Harness执行了你没看到的100个步骤

🧪 现场实验

任务：「从15个网站收集竞争对手的价格，与我们的比较，找出我们贵10%以上的地方，并格式化表格。」

尝试1 —— 聊天中的裸提示词

AI给出漂亮的推理文本、虚构的数字和「怎么做」的建议。它无法访问网站、不记得你的价格、无法验证。

尝试2 —— 带Harness的智能体

系统访问网站、提取价格、在表格中计算差异、验证并交付文件。

区别不是「不同的模型」或「更好的提示词」。同一模型周围的不同基础设施。

🧠 记住

提示词——是与大脑的对话。

Harness——是身体、记忆、手和规则，将聪明的大脑变成有用的员工。

争论「哪个提示词更好」就像争论该用多大声对没有手的人说话。

先给他手。

🛠️ 真实Harness示例

📐 FreeCAD Harness

AI说：「创建一个10×10×10厘米的立方体，在中心添加一个5毫米的孔。」Harness将其翻译成CAD命令——图纸就完成了。

📊 Excel Harness

AI说：「计算季度按地区的平均利润率，构建数据透视表。」Harness打开文件、运行公式、保存。

🎬 Kdenlive Harness

AI说：「从这些片段组装视频，添加转场，叠加音乐。」Harness控制时间线、渲染视频。

✅ 检查清单

  • 我理解为什么提示词只是开始
  • 我能用简单的语言向同事解释Harness
  • 我知道Harness的5个部分：记忆、工具、循环、控制、安全
  • 我理解「在聊天中回答」和「完成工作」的区别
  • 我能为我的程序（Excel、SAP、CAD）举出Harness的例子

📝 测验

问题：你让AI「分析季度报告」。哪项任务不属于Harness？

  1. 在公司文件夹中找到正确的文件
  2. 阅读报告并提取数字
  3. 为报告想一个漂亮的标题
  4. 与上季度核对数字

正确答案：3。标题是模型的工作（文本生成），不是Harness。其余——查找、阅读、验证——属于周围基础设施。
