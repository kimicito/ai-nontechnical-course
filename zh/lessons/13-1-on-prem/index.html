第13级 — 维护与维修

13.1 维护内部任务 — 本地

⏱ 20 分钟 · 面向维护经理 · 封闭循环
封闭循环（本地）
所有任务处理真实设备数据：维护历史、传感器数据、故障记录、备件库存。使用内部模型或本地LLM。

为什么本地部署对维护至关重要

维护数据包含有关设备状态、故障、维修成本和备件库存的敏感信息。这些数据绝不能离开公司边界。

必须保留在本地的数据：
  • 维护和故障历史
  • 传感器数据（振动、温度等）
  • 维护工作记录
  • 备件库存和水平
  • 设备维护成本
  • 预防性维护计划

1. 设备可靠性分析

AI帮助分析故障历史、识别故障模式和预测维护需求。

提示示例
Проанализируй историю отказов оборудования (файл Отказы.xlsx):

1. MTBF по каждому агрегату
2. Топ-5 частых причин отказов
3. Сезонность поломок
4. Связь с типом работ (плановые/аварийные)
5. Стоимость простоя vs стоимость профилактики

Результат: рекомендации по оптимизации ТОиР.

2. 备件库存管理

提示示例
Проанализируй склад запчастей (файл Склад.xlsx):

1. ABC-анализ запчастей
2. Запасы с истекающим сроком годности
3. Критические запчасти с нулевым остатком
4. Расход vs норматив за последний год
5. Рекомендации по заказу

Результат: план закупок + оптимизация складских запасов.

3. 维护计划

提示示例
Составь план ТОиР на следующий квартал:

Данные:
- График плановых работ (файл График.xlsx)
- История отказов (файл Отказы.xlsx)
- Доступность персонала
- Наличие запчастей

Учти:
1. Сезонность производства
2. Критичность оборудования
3. Наличие резерва
4. Бюджет на ТОиР

Результат: оптимизированный график с приоритетами.
