4.6 Skills：扩展智能体能力

⏱ 10 分钟 · 如何查找和安装现成技能
什么是 Skill？
Skill 是一个现成的模块（指令 + 脚本），教智能体执行新操作：检查网站、分析PDF、写邮件、计算指标。无需从头解释 — 只需安装 skill 并说"使用它"。

🗂️ 在哪里查找 Skills

主要目录 — ClawHub：

  • 90,000+ skills 来自 12 个注册表
  • 按类别筛选：商业、开发、创意、研究
  • 社区验证 — 评分和评论
  • 一键安装
有用的 skills 示例：
  • 📊 financial-statement-analyzer — 财务报表分析
  • 🔍 seo-audit — 网站SEO检查
  • 📧 professional-email-composer — 商务邮件
  • 📄 pdf — PDF创建和编辑
  • 🌐 translation-craft — 高质量翻译

⚡ 如何安装 Skill

方法 1：通过 ClawHub（推荐）

clawhub install <skill名称>

示例：

clawhub install financial-statement-analyzer

智能体将下载 skill，阅读说明并准备使用。

方法 2：通过 Hermes Skills Hub

Hermes Agent Skills Hub — 90,000+ skills 来自各种来源：

npx skills add <作者>/<skill> -g

例如：

npx skills add bradautomates/claude-video -g

方法 3：从 GitHub 手动安装

如果 skill 在 GitHub 上 — 将仓库克隆到 skills/ 文件夹：

cd ~/.openclaw/workspace/skills
git clone https://github.com/作者/skill-name.git

🛠️ 如何使用已安装的 Skill

安装后，只需告诉智能体：

"使用 financial-statement-analyzer 分析公司2024年资产负债表"

智能体会读取 SKILL.md，理解合约并完成任务。

🔐 安全：安装前检查

  • ✅ 安装前阅读 SKILL.md — 了解 skill 功能
  • ✅ 检查来源 — 可信作者或注册表
  • ✅ 查看使用的工具 — 仅必要的工具
  • ❌ 不要从可疑网站安装 skills
  • ❌ 未经核实不要让 skills 访问敏感数据

🎯 要点

Skills 是 AI 智能体的"应用程序"。无需从头编程 — 找到现成的，验证后使用。ClawHub 和 Hermes Hub 是您的 skill 商店。
