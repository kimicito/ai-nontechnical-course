6.3 项目：采购部门网站

目标：构建完整的采购部门网站：首页、供应商列表、申请表单、联系页面。

🏗️ 项目结构

采购网站/
├── index.html          # 首页
├── suppliers.html      # 供应商列表
├── request.html        # 采购申请表单
├── contacts.html       # 联系页面
└── style.css           # 样式

📝 分步构建

步骤1：创建首页

提示词："为采购部门创建index.html。页眉：公司logo和导航（首页、供应商、申请、联系）。主视觉区：标题'采购部门'，副标题'为您的企业高效采购'。页脚：联系邮箱。"

步骤2：供应商列表

提示词："创建suppliers.html，包含表格：公司 | 产品 | 联系人 | 评分。添加5个示例供应商。使表格可按评分排序。"

步骤3：申请表单

提示词："创建request.html，包含表单：产品名称、数量、预算、截止日期、备注。添加验证：所有字段必填。使用企业色彩风格。"

步骤4：样式

提示词："创建style.css，包含：蓝色(#2563EB)和白色主题、响应式设计、专业字体、按钮悬停效果。"

🎯 练习

任务：用Cursor构建采购网站。添加您的真实公司名称和3个真实供应商联系人。
