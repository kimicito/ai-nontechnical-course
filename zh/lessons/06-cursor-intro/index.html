6.1 Cursor vs AI聊天：理论与安装

目标：理解Cursor（智能IDE）与聊天式AI的区别。安装Cursor并创建您的第一个程序。

🤖 为什么Cursor改变一切

您已经知道如何与AI聊天。Cursor是下一个级别：AI不只是建议——它编写程序、创建文件、构建完整的网站和数据库。无需手写一行代码。

📊 聊天 vs Cursor：有什么区别？

功能聊天 (ChatGPT, Claude)Cursor
工作环境浏览器、应用代码编辑器内
功能回答、解释编写代码、创建文件
文件访问手动上传查看整个项目
执行您复制粘贴直接运行
最适合问题、分析构建应用

⚡ 您可以在1小时内构建什么

  • 🌐 采购部门网站，带供应商数据库
  • 📊 带图表和分析的仪表板
  • 🤖 回答公司政策问题的机器人
  • 📝 保存数据到Google表格的表单

🛠️ 安装

步骤1：下载Cursor

访问 cursor.com 点击下载。网站会自动检测您的系统。

步骤2：安装并启动

运行安装程序，按照向导操作。首次启动时——连接您的AI提供商（OpenAI、Anthropic或本地Ollama）。

步骤3：创建项目

文件 → 新建文件夹 → 命名为"my-first-project"。完成——您的工作区已准备好！

🎯 练习

任务：安装Cursor，创建新项目，让AI创建一个包含您公司名称的简单HTML页面。尝试聊天和编辑器模式。
