6.4 项目：供应商数据库 + 安全

目标：构建带搜索、过滤和导出的供应商数据库。学习避免常见错误和安全漏洞。

🗄️ 数据库结构

供应商数据库：
- ID (自动)
- 公司名称
- 税号
- 联系人
- 邮箱
- 电话
- 产品（数组）
- 评分（1-5）
- 状态（活跃/非活跃）

📝 构建步骤

步骤1：数据库页面

提示词："创建database.html，带供应商表格。列：公司、税号、联系人、产品、评分。添加按公司名称搜索和按产品类别过滤功能。"

步骤2：添加/编辑表单

提示词："添加'添加供应商'按钮，打开模态表单。字段：公司、税号、联系人、邮箱、电话、产品（逗号分隔）、评分。保存到localStorage。"

步骤3：导出

提示词："添加'导出到Excel'按钮。下载所有供应商数据为格式正确的.xlsx文件。"

⚠️ 常见错误与修复

🐛 错误1：刷新后数据丢失

修复：使用localStorage或连接后端。问："将数据保存到localStorage，使其在页面刷新后持久化。"

🐛 错误2：搜索不工作

修复：检查大小写敏感。问："使搜索不区分大小写，并在所有字段中搜索。"

🐛 错误3：缺少表单验证

修复：添加验证。问："添加验证：邮箱格式、电话号码格式、必填字段。显示错误信息。"

🔒 安全基础

  • 绝不在代码中存储密码
  • 始终验证用户输入
  • 生产环境使用HTTPS
  • 保存前清理数据
  • 定期备份

🎯 练习

任务：构建供应商数据库：添加/编辑/删除、搜索、按评分过滤、导出到Excel。添加10个真实供应商。
