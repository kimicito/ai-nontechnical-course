08.1 Tâches internes — on-prem

⏱ 20 min · pour acheteurs · circuit fermé
Circuit fermé (on-prem)
Toutes les tâches utilisent des données réelles : prix, fournisseurs, contrats, volumes de commandes, historique des livraisons. Utilisez un modèle interne ou un LLM local.
Ce qui doit rester on-prem :
  • Données réelles sur les prix et les conditions contractuelles
  • Noms des fournisseurs et informations sur les relations
  • Volumes de commandes et prévisions
  • Résultats des négociations et positions
  • Données sur la qualité des livraisons
  • Analyses de rentabilité des fournisseurs

1. Analyse des fournisseurs

Exemple de prompt
Проанализируй поставщиков за квартал (файл Поставщики.xlsx):

1. Топ-10 поставщиков по объёму закупок
2. Доля каждого поставщика в общем объёме
3. Своевременность поставок (OTIF)
4. Качество (количество рекламаций)
5. Динамика цен (рост/снижение за год)
6. Рекомендации по оптимизации портфеля

Формат: презентация для руководства

2. Vérification des contrats

Exemple de prompt
Проверь договор поставки (файл Договор.pdf):

1. Соответствие типовому договору компании
2. Рисковые пункты (штрафы, ответственность, форс-мажор)
3. Отсутствующие стандартные положения
4. Несоответствие согласованным условиям
5. Рекомендации по доработке

Формат: протокол проверки с цитатами из договора

3. Analyse des commandes

Exemple de prompt
Проанализируй заказы за месяц (файл Заказы.xlsx):

1. Структура заказов по категориям
2. Средний чек и динамика
3. Товары с ростом закупок (>20%)
4. Товары со снижением закупок
5. Аномалии (резкие скачки, отмены)
6. Рекомендации по прогнозированию

Формат: отчёт с графиками
