6.3 Projet : Site du Service Achats

Objectif : Construire un site web complet pour le service achats : page d'accueil, liste fournisseurs, formulaire de demande, page de contact.

🏗️ Structure du Projet

site-achats/
├── index.html          # Page d'accueil
├── fournisseurs.html   # Liste fournisseurs
├── demande.html        # Formulaire demande d'achat
├── contacts.html       # Page contact
└── style.css           # Style

📝 Construction Étape par Étape

Étape 1 : Créer la Page d'Accueil

Prompt : "Créez index.html pour le service achats. En-tête : logo entreprise et navigation (Accueil, Fournisseurs, Demande, Contacts). Section héro : titre 'Service Achats', sous-titre 'Achats efficaces pour votre entreprise'. Pied de page : email de contact."

Étape 2 : Liste des Fournisseurs

Prompt : "Créez fournisseurs.html avec un tableau : Entreprise | Produits | Contact | Note. Ajoutez 5 fournisseurs exemple. Rendez le tableau triable par note."

Étape 3 : Formulaire de Demande

Prompt : "Créez demande.html avec un formulaire : Nom du produit, Quantité, Budget, Date butoir, Commentaires. Ajoutez la validation : tous les champs obligatoires. Style avec les couleurs corporate."

Étape 4 : Style

Prompt : "Créez style.css avec : thème bleu (#2563EB) et blanc, design responsive, polices professionnelles, effets hover sur les boutons."

🎯 Pratique

Tâche : Construisez le site achats avec Cursor. Ajoutez votre vrai nom d'entreprise et 3 contacts fournisseurs réels.
