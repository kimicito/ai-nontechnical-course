6.2 Prompting pour la Programmation

Objectif : Apprendre à rédiger des prompts qui font construire à Cursor exactement ce dont vous avez besoin.

🎯 Les 5 Règles du Prompting de Code

1. Contexte d'Abord

❌ "Créez un formulaire"

✅ "Créez un formulaire d'enregistrement fournisseur avec les champs : nom de l'entreprise, numéro SIRET, contact, email. Style : corporate, couleurs bleu et blanc."

2. Spécifiez le Format

❌ "Faites un tableau"

✅ "Créez un tableau HTML avec colonnes triables : Fournisseur | Produit | Prix | Délai de livraison. Ajoutez un filtre de recherche en haut."

3. Décrivez le Comportement

❌ "Ajoutez un bouton"

✅ "Ajoutez un bouton 'Exporter vers Excel'. Au clic, téléchargez les données du tableau actuel en fichier .xlsx."

4. Fournissez des Exemples

"Créez un tableau de bord comme ceci : [capture d'écran]. Haut : 3 cartes KPI. Milieu : graphique à barres des achats mensuels. Bas : tableau des transactions récentes."

5. Itérez Étape par Étape

Ne demandez pas tout d'un coup. Construisez par itérations :

  1. "Créez une page HTML de base avec un en-tête"
  2. "Ajoutez un tableau fournisseur avec 3 colonnes"
  3. "Ajoutez la recherche et le tri"
  4. "Appliquez les couleurs corporate"

🔧 Spécial Cursor : Mode Composer

Dans Composer (Ctrl+I), vous pouvez :

  • Écrire des prompts en langage naturel
  • Référencer des fichiers avec @nomfichier
  • Demander à l'IA d'éditer des fonctions spécifiques
  • Obtenir des explications de n'importe quel bloc de code

🎯 Pratique

Tâche : Créez un suivi de tâches simple avec : ajouter une tâche, marquer comme terminée, supprimer. Utilisez le prompting étape par étape.
