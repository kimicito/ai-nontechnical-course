6.1 Cursor vs Chat IA : Théorie & Installation

Objectif : Comprendre la différence entre Cursor (IDE agentique) et les chats IA. Installer Cursor et créer votre premier programme.

🤖 Pourquoi Cursor Change Tout

Vous savez déjà discuter avec l'IA. Cursor est le niveau supérieur : l'IA ne se contente pas de conseiller — elle écrit des programmes, crée des fichiers et construit des sites web et bases de données complets. Sans écrire une seule ligne de code à la main.

⚡ Ce Que Vous Pouvez Construire en 1 Heure

  • 🌐 Site web pour votre service achats avec base de fournisseurs
  • 📊 Tableau de bord avec graphiques et analyses
  • 🤖 Bot qui répond aux questions sur les politiques d'entreprise
  • 📝 Formulaire qui enregistre les données dans Google Sheets

🛠️ Installation

Étape 1 : Télécharger Cursor

Rendez-vous sur cursor.com et cliquez sur Télécharger. Le site détectera automatiquement votre système.

Étape 2 : Installer & Lancer

Exécutez l'installateur, suivez l'assistant. Au premier lancement — connectez votre fournisseur d'IA (OpenAI, Anthropic, ou Ollama local).

Étape 3 : Créer un Projet

Fichier → Nouveau Dossier → nommez-le "mon-premier-projet". C'est prêt — votre espace de travail est opérationnel !

🎯 Pratique

Tâche : Installez Cursor, créez un nouveau projet, et demandez à l'IA de créer une page HTML simple avec le nom de votre entreprise. Essayez les modes chat et composer.
