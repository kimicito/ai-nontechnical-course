11.1 Tâches internes PR — on-prem

⏱ 20 min · pour responsables communication · circuit fermé
Circuit fermé (on-prem)
Toutes les tâches travaillent avec des données internes de communication, des rapports d'activité, des données RH et des plans de communication. Utilisez un modèle interne ou un LLM local.

Pourquoi le on-prem est critique pour la communication

Les données de communication contiennent des informations stratégiques : plans de communication interne, données RH sensibles, informations sur les employés, rapports d'activité confidentiels. Ces données ne doivent jamais quitter le périmètre de l'entreprise.

Ce qui doit rester on-prem :
  • Plans de communication interne
  • Données RH et informations sur les employés
  • Rapports d'activité et indicateurs internes
  • Stratégies de communication
  • Données de sondage interne
  • Informations sur les partenariats non annoncés

1. Préparation de rapports d'activité

L'IA aide à structurer et rédiger des rapports internes basés sur les données réelles de l'entreprise.

Exemple de prompt
Составь ежеквартальный отчёт для сотрудников:

Данные:
- Производственные показатели (файл Показатели.xlsx)
- Кадровые изменения (файл Кадры.xlsx)
- Социальные программы (файл Соцпрограммы.pdf)
- Достижения отделов (папка Достижения/)

Структура:
1. Обзор ключевых результатов
2. Новые проекты и инициативы
3. Кадровые назначения
4. Социальные программы
5. Благодарности и награды

Тон: мотивирующий, профессиональный.

2. Analyse des sondages internes

Exemple de prompt
Проанализируй результаты опроса удовлетворённости сотрудников:

Данные: файл Опрос_2024.xlsx (анонимизированные)

1. Общий индекс удовлетворённости (NPS)
2. Топ-5 проблемных зон
3. Различия по подразделениям
4. Динамика vs предыдущий год
5. Корреляция с текучестью кадров

Результат: отчёт с рекомендациями для HR.

3. Préparation de présentations internes

Exemple de prompt
Подготовь презентацию для совета директоров:

Тема: итоги года в коммуникациях

Данные:
- Метрики внутренних коммуникаций
- Показатели вовлечённости
- Бюджет и ROI
- Планы на следующий год

Формат: 15 слайдов, ключевые цифры, графики.
Тон: стратегический, обоснованный данными.
