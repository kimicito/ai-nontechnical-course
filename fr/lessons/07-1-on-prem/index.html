Niveau 07 — Logistique

07.1 Tâches internes — on-prem

⏱ 20 min · pour logisticiens · circuit fermé
Circuit fermé (on-prem)
Toutes les tâches utilisent des données réelles : mouvements de stocks, routes de transport, stocks, KPI, données sur les fournisseurs. Utilisez un modèle interne ou un LLM local.
Ce qui doit rester on-prem :
  • Données sur les stocks, les mouvements et les rotations
  • Routes de transport réelles, tarifs, contrats
  • Informations sur les fournisseurs et les clients
  • Données sur les retards, les réclamations, les pénalités
  • Rapports et analyses de KPI
  • Données sur les coûts de transport et de stockage

1. Optimisation des stocks

Exemple de prompt
Проанализируй оборачиваемость запасов за квартал (файл Запасы.xlsx):

1. ABC-анализ: какие SKU дают 80% выручки
2. XYZ-анализ: стабильность спроса
3. Товары с избытком (запас > 90 дней)
4. Товары с дефицитом (stockout за период)
5. Рекомендации по reorder point и safety stock

Формат: таблица + график + рекомендации

2. Планирование маршрутов

Exemple de prompt
Построй оптимальные маршруты доставки:

Данные:
- Склады: [УКАЖИТЕ]
- Клиенты: [УКАЖИТЕ]
- Объёмы: [УКАЖИТЕ]
- Ограничения: [УКАЖИТЕ] (время работы, габариты)

Критерии:
- Минимизация пробега
- Соблюдение окон доставки
- Загрузка транспорта ≥85%

Формат: маршрутный лист с временными интервалами

3. ABC-анализ склада

Exemple de prompt
Проведи ABC-анализ склада (файл Склад.xlsx):

1. Категоризация по частоте обращения (A/B/C)
2. Рекомендации по размещению (A — у выдачи, C — дальше)
3. Анализ ошибок комплектации по зонам
4. Рекомендации по перерасстановке

Формат: карта зон + таблица + рекомендации

4. График поставок

Exemple de prompt
Составь график поставок на месяц:

Данные:
- Потребность в сырье (файл Потребность.xlsx)
- Остатки на складах
- Сроки поставки от поставщиков
- Минимальные партии

Ограничения:
- Объём складских помещений
- Бюджет на закупки
- Сезонность спроса

Формат: график поставок с датами и объёмами
