4.6 Skills : étendre les capacités de l'agent

⏱ 10 min · comment trouver et installer des compétences prêtes à l'emploi
Qu'est-ce qu'un Skill ?
Un Skill est un module prêt à l'emploi (instructions + scripts) qui apprend à l'agent une nouvelle action : vérifier un site, analyser un PDF, rédiger un email, calculer des métriques. Au lieu d'expliquer à l'agent depuis zéro — installez simplement le skill et dites « utilise-le ».

🗂️ Où trouver les skills

Catalogue principal — ClawHub :

  • 90 000+ skills de 12 registres
  • Filtres par catégorie : business, développement, créatif, recherche
  • Vérifié par la communauté — notes et avis
  • Installation en une commande
Exemples de skills utiles :
  • 📊 financial-statement-analyzer — analyse financière
  • 🔍 seo-audit — vérification SEO
  • 📧 professional-email-composer — emails professionnels
  • 📄 pdf — création et édition PDF
  • 🌐 translation-craft — traduction de qualité

⚡ Comment installer un skill

Méthode 1 : Via ClawHub (recommandé)

clawhub install <nom-du-skill>

Exemple :

clawhub install financial-statement-analyzer

L'agent télécharge le skill, lit les instructions et est prêt à l'emploi.

Méthode 2 : Via Hermes Skills Hub

Hermes Agent Skills Hub — 90 000+ skills de diverses sources :

npx skills add <auteur>/<skill> -g

Par exemple :

npx skills add bradautomates/claude-video -g

Méthode 3 : Manuellement depuis GitHub

Si le skill est sur GitHub — clonez le dépôt dans le dossier skills/ :

cd ~/.openclaw/workspace/skills
git clone https://github.com/auteur/skill-name.git

🛠️ Comment utiliser un skill installé

Après l'installation, dites simplement à l'agent :

« Analyse le bilan 2024 de l'entreprise avec financial-statement-analyzer »

L'agent lit SKILL.md, comprend le contrat et exécute la tâche.

🔐 Sécurité : vérifiez avant d'installer

  • ✅ Lisez SKILL.md avant l'installation
  • ✅ Vérifiez la source — auteur ou registre de confiance
  • ✅ Voyez quels outils il utilise
  • ❌ N'installez pas de skills depuis des sites suspects
  • ❌ Ne donnez pas l'accès aux données sensibles sans vérification

🎯 L'essentiel

Les skills sont des « applications » pour votre agent IA. Au lieu de programmer depuis zéro — trouvez du prêt à l'emploi, vérifiez et utilisez. ClawHub et Hermes Hub sont vos magasins de skills.
