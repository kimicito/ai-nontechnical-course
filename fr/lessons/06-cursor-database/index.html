6.4 Projet : Base de Données Fournisseurs + Sécurité

Objectif : Construire une base de données fournisseurs avec recherche, filtres et export. Apprendre à éviter les erreurs courantes et les failles de sécurité.

🗄️ Structure de la Base de Données

Base de Données Fournisseurs :
- ID (auto)
- Nom Entreprise
- Numéro SIRET
- Contact
- Email
- Téléphone
- Produits (tableau)
- Note (1-5)
- Statut (Actif/Inactif)

📝 Étapes de Construction

Étape 1 : Page Base de Données

Prompt : "Créez database.html avec un tableau fournisseurs. Colonnes : Entreprise, SIRET, Contact, Produits, Note. Ajoutez la recherche par nom d'entreprise et le filtre par catégorie de produit."

Étape 2 : Formulaires Ajout/Édition

Prompt : "Ajoutez un bouton 'Ajouter Fournisseur' qui ouvre un formulaire modal. Champs : Entreprise, SIRET, Contact, Email, Téléphone, Produits (séparés par virgules), Note. Enregistrez dans localStorage."

Étape 3 : Export

Prompt : "Ajoutez un bouton 'Exporter vers Excel'. Téléchargez toutes les données fournisseurs en fichier .xlsx avec un formatage correct."

⚠️ Erreurs Courantes & Corrections

🐛 Erreur 1 : Perte de Données au Rafraîchissement

Correction : Utilisez localStorage ou connectez un backend. Demandez : "Enregistrez les données dans localStorage pour qu'elles persistent après le rafraîchissement de la page."

🐛 Erreur 2 : Recherche Qui Ne Fonctionne Pas

Correction : Vérifiez la sensibilité à la casse. Demandez : "Rendez la recherche insensible à la casse et recherchez dans tous les champs."

🐛 Erreur 3 : Validation du Formulaire Absente

Correction : Ajoutez la validation. Demandez : "Ajoutez la validation : format email, format téléphone, champs obligatoires. Affichez les messages d'erreur."

🔒 Bases de Sécurité

  • Ne jamais stocker les mots de passe dans le code
  • Toujours valider les entrées utilisateur
  • Utilisez HTTPS en production
  • Assainissez les données avant enregistrement
  • Sauvegardes régulières

🎯 Pratique

Tâche : Construisez la base de données fournisseurs avec : ajout/édition/suppression, recherche, filtre par note, export vers Excel. Ajoutez 10 vrais fournisseurs.
