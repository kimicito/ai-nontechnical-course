6.4 Project: Supplier Database + Security

Goal: Build a supplier database with search, filtering, and export. Learn to avoid common errors and security mistakes.

🗄️ Database Structure

Supplier Database:
- ID (auto)
- Company Name
- INN/Tax ID
- Contact Person
- Email
- Phone
- Products (array)
- Rating (1-5)
- Status (Active/Inactive)

📝 Build Steps

Step 1: Database Page

Prompt: "Create database.html with supplier table. Columns: Company, INN, Contact, Products, Rating. Add search by company name and filter by product category."

Step 2: Add/Edit Forms

Prompt: "Add 'Add Supplier' button that opens modal form. Fields: Company, INN, Contact, Email, Phone, Products (comma-separated), Rating. Save to localStorage."

Step 3: Export

Prompt: "Add 'Export to Excel' button. Download all supplier data as .xlsx file with proper formatting."

⚠️ Common Errors & Fixes

🐛 Error 1: Data Loss on Refresh

Fix: Use localStorage or connect to backend. Ask Cursor: "Save data to localStorage so it persists after page refresh."

🐛 Error 2: Search Not Working

Fix: Check case sensitivity. Ask: "Make search case-insensitive and search across all fields."

🐛 Error 3: Form Validation Missing

Fix: Add validation. Ask: "Add validation: email format, phone number format, required fields. Show error messages."

🔒 Security Basics

  • Never store passwords in code
  • Always validate user input
  • Use HTTPS for production
  • Sanitize data before saving
  • Regular backups

🎯 Practice

Task: Build supplier database with: add/edit/delete, search, filter by rating, export to Excel. Add 10 real suppliers.
