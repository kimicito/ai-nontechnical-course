4.7 Harness: How AI Gets Hands

⏱ 12 min · why the prompt is only 5% of the result
Main illusion: write a "smart prompt" and AI will solve the task.

In reality, the prompt is 5% of the result. The other 95% is memory, tools, cycles, and control. That is Harness.

🧑‍💼 The Intern with Amnesia

Imagine a brilliant intern. Incredibly well-read — half the internet. But he has problems:

  • Amnesia — doesn't remember yesterday's discussion. Every time — from scratch.
  • No hands — can't open Excel, visit a website, send an email.
  • Confidently wrong — speaks beautifully, but may invent facts.
  • One-shot worker — gives an answer and disappears. No "try → fail → fix".
Question: how many real tasks would you trust to this intern with just a good brief (prompt)?

Answer: almost none. He needs an environment. That environment is Harness.

🔧 5 Parts of Harness

1. Memory and Context — "the intern's secretary"

Someone must prepare a folder before each meeting: "Here's the contract, the previous correspondence, the regulations." Harness chooses what to show the model from thousands of documents.

Example: "Update our commercial proposal." A prompt doesn't decide — which of the 40 proposals, where it lives, which version is latest. The surrounding system does.

2. Tools — "the intern's hands"

The model only generates text. It cannot:

  • Google the exchange rate
  • Open your CRM
  • Calculate in real Excel
  • Send an email

Harness gives buttons: "search", "calculator", "read file", "send email".

Difference: a consultant says "you need to check 50 contracts." An employee checked them and brought a table.

3. Work Cycle — "not one answer, but a workday"

Complex tasks are solved in a loop:

Think → do step → look at result → spot error → fix → next step…

One prompt is like one breath. You can't run a marathon on one breath. Harness spins the loop 10, 50, 100 times.

Example: "Analyze 200 customer reviews." A prompt — gives beautiful but made-up summary. A harness agent — reads in batches, counts, verifies, and shows which reviews it relied on.

4. Quality Control — "the boss who signs off"

The intern confidently makes mistakes. So you need checks: source verification, second look before sending to the client.

"Please don't make mistakes" in a prompt is like a "don't worry" sticker on the desk. You need a mechanism, not a request.

5. Boundaries and Safety — "access and regulations"

You don't give a new intern the safe keys on day one. Harness defines: which files to read, where to write, how many attempts, when to ask a human.

Without boundaries an agent may: delete the wrong files, loop forever, send an email to the wrong person.

👁️ What You See vs What Actually Happens

What you seeWhat actually happens
"I wrote a smart prompt"The system gathered context from your files and history
"AI searched the internet"Harness called a search tool and fed results to the model
"AI fixed its own mistake"Harness ran a cycle: attempt → error → retry
"AI made a report in 20 min"Harness executed 100 steps you didn't see

🧪 Live Experiment

Task: "Collect competitor prices from 15 websites, compare with ours, find where we're 10%+ more expensive, and format a table."

Attempt 1 — bare prompt in chat

AI gives a beautiful reasoning text, invented numbers, and advice on "how you'd do it." It has no access to websites, no memory of your prices, no way to verify.

Attempt 2 — agent with Harness

The system visits websites, extracts prices, calculates differences in a table, verifies, and delivers a file.

The difference is not "a different model" or "a better prompt." Different infrastructure around the same model.

🧠 Remember

Prompt — is a conversation with a brain.

Harness — is the body, memory, hands, and rules that turn a smart brain into a useful employee.

Arguing "which prompt is better" is like arguing how loudly to talk to a person with no hands.

First, give them hands.

🛠️ Real-World Harness Examples

📐 FreeCAD Harness

AI says: "Create a 10×10×10 cm cube, add a 5 mm hole in the center." Harness translates this into CAD commands — and the drawing is ready.

📊 Excel Harness

AI says: "Calculate average margin by region for the quarter, build a pivot table." Harness opens the file, runs formulas, saves.

🎬 Kdenlive Harness

AI says: "Assemble a video from these clips, add transitions, overlay music." Harness controls the timeline, renders the video.

✅ Checklist

  • I understand why a prompt is just the beginning
  • I can explain Harness in simple words to a colleague
  • I know the 5 parts of Harness: memory, tools, cycle, control, safety
  • I understand the difference between "answered in chat" and "did the work"
  • I can give an example of Harness for my program (Excel, SAP, CAD)

📝 Quiz

Question: You ask AI to "analyze the quarterly report." What is NOT a Harness task?

  1. Find the right file in company folders
  2. Read the report and extract numbers
  3. Come up with a beautiful title for the report
  4. Verify numbers against last quarter

Correct answer: 3. The title is the model's job (text generation), not Harness. The rest — finding, reading, verifying — is surrounding infrastructure.
