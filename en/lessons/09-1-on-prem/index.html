Level 9 — Construction

9.1 Internal Tasks: On-Prem

⏱ 20 min · for construction managers · closed loop
Closed loop (on-prem)
All tasks work with real project data, estimates, schedules, and contractor documentation. Use internal model or local LLM.

Why on-prem is critical for construction

Construction projects contain sensitive data: cost estimates, contractor pricing, project timelines, technical specifications. This data must stay within the company perimeter.

What must stay on-prem:
  • Cost estimates and budgets
  • Contractor pricing and bids
  • Project schedules and milestones
  • Technical specifications and drawings
  • Quality control reports
  • Contract terms and penalties

1. Estimate analysis and verification

AI helps verify construction estimates by comparing with historical data, norms, and detecting anomalies.

Prompt example
Проанализируй смету на строительство склада (файл Смета.xlsx):

1. Сравни с типовыми нормативами (файл Нормативы.xlsx)
2. Найди позиции с отклонением более 20% от нормы
3. Проверь расход материалов на единицу работ
4. Выяви дублирующиеся позиции
5. Дай рекомендации по оптимизации

Результат: таблица с аномалиями и рекомендациями.

2. Schedule analysis

Check project schedules for conflicts, critical path issues, and resource overlaps.

Prompt example
Проанализируй график строительства (файл График.mpp или .xlsx):

1. Найди критический путь
2. Выяви пересечения работ (когда две бригады нужны одновременно)
3. Проверь логику связей (нет ли циклов)
4. Найди работы без предшественников или последователей
5. Оцени риски просрочки по каждому этапу

Результат: список проблемных зон с рекомендациями.

3. Quality control documentation

Generate and verify quality control reports, acceptance certificates, and defect lists.

Prompt example
Подготовь акт приёмки работ по этапу "Бетонирование фундамента":

Данные:
- Объём работ: [УКАЖИТЕ] м³
- Дата выполнения: [УКАЖИТЕ]
- Подрядчик: [УКАЖИТЕ]
- Результаты лабораторных испытаний: [УКАЖИТЕ]
- Выявленные дефекты: [УКАЖИТЕ]

Формат: по шаблону компании (файл Шаблон_акта.docx).

4. Contractor performance analysis

Prompt example
Оцени подрядчика "СтройПрогресс" по данным за 2 года:

- Количество выполненных контрактов: [УКАЖИТЕ]
- Среднее отклонение от сроков: [УКАЖИТЕ] дней
- Количество претензий по качеству: [УКАЖИТЕ]
- Средняя экономия по итогам работ: [УКАЖИТЕ]%
- Финансовые показатели: [УКАЖИТЕ]

Оцени по шкале 1–10:
1. Соблюдение сроков
2. Качество работ
3. Финансовая стабильность
4. Работа с претензиями

Рекомендация: продлевать контракт, ограничить объём, заменить.
