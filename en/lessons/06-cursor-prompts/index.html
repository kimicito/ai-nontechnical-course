6.2 Prompting for Coding

Goal: Learn to write prompts that make Cursor build exactly what you need.

🎯 The 5 Rules of Coding Prompts

1. Context First

❌ "Create a form"

✅ "Create a supplier registration form with fields: company name, INN, contact person, email. Style: corporate, colors blue and white."

2. Specify Format

❌ "Make a table"

✅ "Create an HTML table with sortable columns: Supplier | Product | Price | Delivery time. Add search filter at the top."

3. Describe Behavior

❌ "Add a button"

✅ "Add 'Export to Excel' button. When clicked, download current table data as .xlsx file."

4. Provide Examples

"Create a dashboard like this: [screenshot]. Top: 3 KPI cards. Middle: bar chart of monthly purchases. Bottom: recent transactions table."

5. Iterate Step by Step

Don't ask for everything at once. Build in iterations:

  1. "Create basic HTML page with header"
  2. "Add supplier table with 3 columns"
  3. "Add search and sort functionality"
  4. "Style with corporate colors"

🔧 Cursor Special: Composer Mode

In Composer (Ctrl+I), you can:

  • Write prompts in natural language
  • Reference files with @filename
  • Ask AI to edit specific functions
  • Get explanations of any code block
