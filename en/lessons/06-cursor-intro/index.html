6.1 Cursor vs AI Chat: Theory & Setup

Goal: Understand the difference between Cursor (agentic IDE) and chat-based AI. Install Cursor and make your first program.

🤖 Why Cursor Changes Everything

You already know how to chat with AI. Cursor is the next level: AI doesn't just advise — it writes programs, creates files, and builds complete websites and databases. Without writing a single line of code by hand.

📊 Chat vs Cursor: What's the Difference?

FeatureChat (ChatGPT, Claude)Cursor
Where it worksBrowser, appInside code editor
What it doesAnswers, explainsWrites code, creates files
File accessUpload files manuallySees entire project
ExecutionYou copy-pasteRuns directly
Best forQuestions, analysisBuilding applications

⚡ What You Can Build in 1 Hour

  • 🌐 Website for your procurement department with supplier database
  • 📊 Dashboard with charts and analytics
  • 🤖 Bot that answers questions about company policies
  • 📝 Form that saves data to Google Sheets

🛠️ Installation

Step 1: Download Cursor

Go to cursor.com and click Download. The site will auto-detect your OS.

Step 2: Install & Launch

Run installer, follow wizard. On first launch — connect your AI provider (OpenAI, Anthropic, or local Ollama).

Step 3: Create Project

File → New Folder → name it "my-first-project". That's it — your workspace is ready!

🎯 Practice

Task: Install Cursor, create a new project, and ask AI to create a simple HTML page with your company name. Try both chat and composer modes.
