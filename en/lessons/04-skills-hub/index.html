4.6 Skills: Extending Your Agent

⏱ 10 min · how to find and install ready-made skills
What is a Skill?
A Skill is a ready-made module (instructions + scripts) that teaches your agent a new action: checking a website, analyzing PDFs, writing emails, calculating metrics. Instead of explaining from scratch — just install the skill and say "use it".

🗂️ Where to Find Skills

Main catalog — ClawHub:

  • 90,000+ skills from 12 registries
  • Filters by category: business, development, creative, research
  • Community-verified — ratings and reviews
  • One-command installation
Useful skills examples:
  • 📊 financial-statement-analyzer — financial report analysis
  • 🔍 seo-audit — website SEO check
  • 📧 professional-email-composer — business emails
  • 📄 pdf — PDF creation and editing
  • 🌐 translation-craft — quality translation

⚡ How to Install a Skill

Method 1: Via ClawHub (recommended)

clawhub install <skill-name>

Example:

clawhub install financial-statement-analyzer

The agent downloads the skill, reads the instructions, and is ready to use.

Method 2: Via Hermes Skills Hub

Hermes Agent Skills Hub — 90,000+ skills from various sources:

npx skills add <author>/<skill> -g

For example:

npx skills add bradautomates/claude-video -g

Method 3: Manually from GitHub

If the skill is on GitHub — clone the repository into your skills/ folder:

cd ~/.openclaw/workspace/skills
git clone https://github.com/author/skill-name.git

🛠️ How to Use an Installed Skill

After installation, simply tell your agent:

"Analyze the company's 2024 balance sheet using financial-statement-analyzer"

Or:

"Check example.com for SEO issues"

The agent reads SKILL.md, understands the contract, and completes the task.

🔐 Security: Check Before Installing

  • ✅ Read SKILL.md before installing — what does the skill do
  • ✅ Check the source — trusted author or registry
  • ✅ See what tools it uses — only necessary ones
  • ❌ Don't install skills from suspicious sites
  • ❌ Don't give skills access to sensitive data without verification

📋 Checklist: First Installation

  1. Define the task (what you want to automate)
  2. Search for a skill on ClawHub
  3. Read the description and reviews
  4. Install: clawhub install <name>
  5. Test on safe data
  6. Use in production

🎯 Key Takeaway

Skills are "apps" for your AI agent. Instead of programming from scratch — find ready-made, verify, and use. ClawHub and Hermes Hub are your skill stores.
