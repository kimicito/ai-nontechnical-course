8.1 Internal Tasks: On-Premise

15 min · for procurement specialists · closed loop

This lesson covers tasks that a procurement specialist performs inside the company with data that cannot be sent to the internet. Prices, terms, negotiation positions — all of this is trade secret.

Solution: on-premise LLM (e.g., Qwen) within the company's closed perimeter. Data never leaves the perimeter.

Why On-Premise for Procurement

What cannot be sent to the cloud:
  • Specific supplier prices from quotations
  • Contract terms and penalties
  • Negotiation position (BATNA, leverage)
  • Purchase volumes by item
  • Historical supplier data
What can be done on-premise:
  • Compare 5 quotations by price, lead time, and terms — in 2 minutes
  • Check if an offer matches the technical specification
  • Prepare arguments for negotiations
  • Find deviations in a contract from the template
  • Analyze purchasing patterns over 2 years

1. Comparative Quotation Analysis

A procurement specialist receives 3–5 quotations. Previously: manually compile in Excel, compare price, delivery time, payment terms, warranties. Now: upload to an on-premise LLM and ask a question.

Prompt example
У меня 3 коммерческих предложения на поставку насосов. 
Приложены файлы КП1, КП2, КП3.

Сделай сравнительную таблицу:
- Цена за единицу
- Срок поставки
- Условия оплаты
- Гарантийный срок
- Стоимость доставки

Выдели лучшее предложение по каждому критерию и итоговый победитель.
Result: comparison table + visual highlighting of best positions. The procurement specialist saves 20–30 minutes of routine work.

2. Checking an Offer Against the Technical Specification

Often a supplier responds to a technical specification, but with caveats or deviations. An LLM can find these deviations faster than a human.

Prompt example
Сравни техническое задание (файл ТЗ.docx) и ответ поставщика (файл Ответ.docx).

Найди:
1. Полные отклонения от ТЗ (что не соответствует)
2. Частичные отклонения (что соответствует с оговорками)
3. Пропущенные пункты (на что поставщик не ответил)

Сделай список с указанием конкретных пунктов ТЗ.

3. Preparation for Negotiations

This is the most sensitive task. BATNA (best alternative to a negotiated agreement), pressure leverage, supplier weak points — none of this can be exposed in the cloud. On-premise solves this problem.

Prompt example
Я готовлюсь к переговорам с поставщиком X по закупке оборудования.

Вот мои данные:
- Есть 2 альтернативных поставщика с ценами на 15% ниже
- Текущий поставщик задержал поставку в прошлом квартале на 2 недели
- Мне нужна поставка за 3 недели, а у него стандартно 6 недель
- Объём закупки — 50 единиц, это крупный заказ для его категории

Подготовь:
1. Мои аргументы для снижения цены
2. Рычаги давления (вежливо, но убедительно)
3. BATNA — что делать, если не договоримся
4. Сценарий переговоров (по шагам)

4. Contract Verification

A lawyer checks a contract for a week. An LLM finds deviations from the template in minutes — the lawyer then validates the findings.

Prompt example
Сравни договор поставщика (файл Договор.docx) и наш стандартный шаблон (файл Шаблон.docx).

Найди отклонения по:
- Ответственности сторон
- Штрафным санкциям
- Срокам поставки
- Условиям оплаты
- Порядку разрешения споров

Для каждого отклонения укажи: где в шаблоне, где в договоре, риск для нас.

5. SKU Normalization

Within a company, 5 departments may call the same product differently: "насос Grundfos 32-160", "насос Грюндфос 32-160", "GRUNDFOS 32-160". An LLM brings them to a unified form.

Prompt example
Вот список номенклатуры из 3 подразделений (файл Номенклатура.xlsx).

Приведи к единому виду:
- Унифицируй названия брендов (латиница)
- Стандартизируй единицы измерения
- Убери дубли
- Создай таблицу соответствия: старое название → новое название

Сохрани результат в Excel.

6. Purchase History Analysis

A procurement specialist wants to understand: are prices from a regular supplier rising? Is there seasonality? Which items are getting more expensive the fastest?

Prompt example
У меня история закупок за 2 года (файл История.xlsx).

Проанализируй:
1. Динамика цен по топ-10 поставщикам (тренд роста/падения)
2. Сезонность (какие месяцы дороже)
3. Топ-5 позиций с максимальным ростом цены
4. Среднее время между заказом и поставкой по поставщикам
5. Рекомендации: где есть риск роста цен, на что обратить внимание

7. Supplier Risk Scoring

Combining internal supplier data with a risk assessment template. The LLM calculates the score and explains why.

Prompt example
Оцени риск поставщика "ПромТехСнаб" по данным:

- Работаем 3 года
- 2 задержки поставок за последний год (на 5 и 12 дней)
- 1 претензия по качеству (брак 3%, устранили за свой счёт)
- Цена на 8% ниже рынка
- Финансовые показатели: выручка растёт, нет судебных дел
- Контракт до конца года, потом перетендер

По шкале от 1 до 10:
1. Общий риск-профиль
2. Риск операционный (срыв сроков)
3. Риск финансовый
4. Риск качества

Дай рекомендацию: продлевать, перетендеровать, искать резерв.

8. Transport Document Parsing

Waybills, invoices, CMR — an LLM extracts data and cross-checks it against the order. All within the internal perimeter.

Prompt example
Файл ТТН.pdf — разбери содержимое:

- Номер ТТН, дата
- Отправитель и получатель
- Перечень груза с количеством и весом
- Сумма груза
- Дата отгрузки и дата доставки (факт vs план)

Сверь с заказом (файл Заказ.xlsx) и выяви:
- Недостачи
- Пересорты
- Отклонения по срокам

9. Management Reports

A procurement specialist spends an evening on PowerPoint. An LLM produces a draft in 10 minutes — only the numbers need to be verified.

Prompt example
На основе данных из файла Закупки_Q3.xlsx подготовь черновик отчёта для совета директоров:

1. Общий объём закупок (сумма, рост vs Q2)
2. Топ-5 категорий по сумме
3. Статус по ключевым проектам (в срок / с рисками / просрочены)
4. Рекомендации по 2–3 проблемным зонам
5. План на Q4 (кратко)

Формат: структурированный текст, готовый к вставке в презентацию.

Knowledge Check

Question 1: Why can't quotation comparison be sent to cloud-based ChatGPT?

Because ChatGPT works slowly
Because supplier prices are trade secrets
Because ChatGPT cannot read Excel

Question 2: Which tool should be used for BATNA-based negotiation preparation?

Google Docs
On-premise LLM in a closed loop
ChatGPT with data deletion afterwards

Question 3: How much time does an LLM save on comparing 5 quotations?

It doesn't save time; manual is faster
30 minutes → 2 minutes
5 minutes → 4 minutes

Question 4: What is supplier risk scoring?

Risk assessment on a 1–10 scale based on internal data
Credit history check at a bank
Searching for supplier reviews online

Question 5: Which of these documents definitely belongs on-premise?

Draft TS without prices
Contract with specific penalties and terms
Translation of an instruction from English
