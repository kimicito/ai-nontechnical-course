9.5 Agent Scenarios for Construction

⏱ 12 min · automating construction processes with agents
How is an agent different from a language model?
An LLM answers single requests. An agent works cyclically: receives data, analyzes, makes decisions, performs actions — without human involvement at each step. More — Level 4.

Scenario 1: Defect Tracking Agent (n8n + Vision API)

Task: receive photos from the site, classify defects, assign responsible parties, track resolution.

[Telegram bot on site: photo + defect description]
↓
[n8n: receive message]
↓
[Vision LLM: classify defect (crack, unevenness, material defect)]
↓
[LLM: determine criticality (critical / serious / cosmetic)]
↓
[Notion/Bitrix24: create task with photo, description, deadline]
↓
[Assign responsible per directory: defect type → department]
↓
[Notify responsible in Telegram]
Result: defect is recorded in 2 minutes instead of 2 hours (photo → paper act → journal entry → routing).

Scenario 2: Estimate Verification Agent (OpenClaw-style Agent)

Task: upload an estimate, check against norms (FER/GESN), find errors, prepare comments.

[Upload estimate file (Excel, PDF) to system]
↓
[On-premise agent: extract items]
├─→ Check: compliance with FER/GESN (internal database)
├─→ Check: volume calculation
├─→ Check: coefficients and adjustments
└─→ Check: regional rates
↓
[LLM: form verification protocol]
├─ Found errors
├─ Correction recommendations
└─ References to normative documents
↓
[PDF protocol + notification to estimator]

Scenario 3: Schedule Control Agent (Hybrid)

Task: monitor work schedules, analyze delay risks, warn responsible parties.

[Integration with Project / MS Project / Primavera]
↓
[Agent: daily status reading]
├─→ Plan/fact comparison
├─→ Critical path analysis
└─→ Identify tasks at risk of delay (>3 days deviation)
↓
[LLM: formulate warning]
├─ Which work is at risk
├─ Why (causes per data)
└─ What to do (options)
↓
[Email to project manager + dashboard update]
Important: schedule data is internal information. The agent works fully on-premise or through DMZ with filtering.
