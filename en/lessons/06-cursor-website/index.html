6.3 Project: Procurement Department Website

Goal: Build a complete procurement department website: homepage, supplier list, request form, contact page.

🏗️ Project Structure

procurement-site/
├── index.html          # Homepage
├── suppliers.html      # Supplier list
├── request.html        # Procurement request form
├── contacts.html       # Contact page
└── style.css           # Styling

📝 Step-by-Step Build

Step 1: Create Homepage

Prompt: "Create index.html for procurement department. Header: company logo and navigation (Home, Suppliers, Request, Contacts). Hero section: title 'Procurement Department', subtitle 'Efficient purchasing for your business'. Footer: contact email."

Step 2: Supplier List

Prompt: "Create suppliers.html with table: Company | Products | Contact | Rating. Add 5 sample suppliers. Make table sortable by rating."

Step 3: Request Form

Prompt: "Create request.html with form: Product name, Quantity, Budget, Deadline, Comments. Add validation: all fields required. Style with corporate colors."

Step 4: Styling

Prompt: "Create style.css with: blue (#2563EB) and white theme, responsive design, professional fonts, hover effects on buttons."

🎯 Practice

Task: Build the procurement website with Cursor. Add your real company name and 3 real supplier contacts.
